# VFlasher
Welcome to the Qualcomm and Arduino without Ubuntu project!
This uses a custom flasher called VFlasher made by me! To use it run: `sudo ./vflasher <board-manufacturer (e.g. qualcomm)> <board-name (e.g. yun)> <os (e.g. fedora)>` or use the Windows GUI.
To install VFlasher locally so that you can type just `vflasher` anywhere, run `mkdir $HOME/.bin && mv /path/to/your/vflasher $HOME/.bin` and add $HOME/.bin to your PATH in `.bashrc` on UNIX/Linux/macOS/BSD, or on Windows, use the setup wizard for the Windows GUI.
